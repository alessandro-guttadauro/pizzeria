# 🍕 Pizzeria Da Noi

Sito web statico di una pizzeria, realizzato solo con **HTML** e **CSS**, senza JavaScript né framework.

## Pagine

| Pagina | Descrizione |
| --- | --- |
| `index.html` | Home con presentazione della pizzeria e pizze in evidenza |
| `menu.html` | Menù completo con pizze, bevande e prezzi |
| `contatti.html` | Indirizzo, orari di apertura e modulo di prenotazione |

## Struttura del progetto

```
pizzeria/
├── index.html
├── menu.html
├── contatti.html
├── css/
│   └── style.css
└── README.md
```

## Come aprirlo

1. Clona il repository:
   ```bash
   git clone https://github.com/alessandro-guttadauro/pizzeria.git
   ```
2. Apri `index.html` nel browser.

Non serve installare nulla.

## Caratteristiche

- Layout responsive con Flexbox e Grid
- Barra di navigazione comune a tutte le pagine
- Colori e font definiti con variabili CSS
- Modulo di prenotazione (solo grafico)
